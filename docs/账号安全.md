# 账号安全
星辰商城重视用户的账号安全。本页说明密码设置建议、登录异常处理和账号注销流程。

## 密码设置建议
密码长度至少 8 位，建议包含字母、数字和符号，避免使用生日、手机号等容易被猜到的信息。不要与其他网站使用相同密码。星辰商城不会以任何形式索要你的密码。如忘记密码，则通过手机号验证找回登录

## 登录异常处理
异地登录、频繁验证失败会触发账号保护，账号将被临时冻结 2 小时，可通过手机验证码自助解冻。若发现账号有非本人操作，请立即修改密码并联系客服处理。

## 账号注销
在「设置 → 账号安全 → 注销账号」可自助申请注销。注销前需处理完所有进行中的订单并退回钱包余额。注销后账号数据保留 30 天用于反欺诈核查，之后永久删除。
