# 支付方式
星辰商城支持多种主流支付方式。本页说明可用的支付渠道、分期付款规则和发票开具流程。

## 支持的支付渠道
支持微信支付、支付宝、主流银行卡（储蓄卡和信用卡）以及星辰钱包余额支付。星辰钱包可绑定银行卡充值，充值金额不可提现，可用于购买任意商品。

## 分期付款
订单金额满 500 元可使用信用卡分期或星辰分期，支持 3 期、6 期、12 期。星辰分期部分商品免手续费，具体以结算页显示为准。分期订单发生退款时，已出账单的期数由银行原路退回。

## 发票开具
支持电子普通发票和增值税专用发票。下单时可选择开具发票，电子发票在发货后 24 小时内发送至预留邮箱。专票需提供企业税号，每月统一开具一次。
