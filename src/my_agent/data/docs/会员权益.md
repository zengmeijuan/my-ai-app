# 会员权益
星辰商城会员体系分为星辰卡、银河卡、宇宙卡三个等级。本页说明等级规则、积分规则和各等级的专属权益。

## 会员等级规则
自然年内累计消费满 1000 元升级银河卡，满 5000 元升级宇宙卡。等级有效期一年，次年重新累计。等级越高，享受的权益越多。

## 积分规则
每消费 1 元积 1 分，评价晒单可获得额外积分。积分可在积分商城兑换商品或下单抵现，100 积分抵 1 元。积分自获得之日起一年内有效，过期自动清零。

## 会员专享权益
银河卡会员每月获得一张免运费券，宇宙卡会员不限次免运费。此外，宇宙卡会员享有专属客服通道和生日礼包。免运费券在结算时自动抵扣运费，不可转让、不可变现。
