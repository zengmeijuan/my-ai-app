# 退货政策
星辰商城提供完善的售后服务，支持七天无理由退货和质量问题退换货。本页说明退货条件、退款到账时间和不支持退货的例外情况。

## 七天无理由退货的条件
签收后 7 天内可申请无理由退货，商品需保持吊牌完整、配件齐全、不影响二次销售。申请入口：我的订单 → 申请售后。审核通过后按页面提示寄回商品；非质量问题的寄回运费由用户承担。

## 退款多久到账
退款在售后审核通过后原路退回：微信和支付宝通常 1-3 个工作日到账，银行卡 3-7 个工作日到账，星辰钱包余额实时到账。节假日可能顺延，如超过 7 个工作日仍未到账，请联系客服查询。

## 不支持退货的商品
贴身内衣、袜子、食品饮料、定制商品、已激活的电子产品不支持七天无理由退货。商品存在质量问题的不受此限制，可随时申请退换。
